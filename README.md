# తెలుగు వార్తలు - Telugu News Site

ఈ Astro ప్రాజెక్ట్ తెలుగు భాషలో వార్తలను అందించే వెబ్‌సైట్. అఫిలియేట్ మోనెటైజేషన్ మరియు AdSense బదులుగా సురక్షితమైన ప్రకటనలు ఉపయోగిస్తుంది.

## Features:

- ✅ తెలుగు వార్తలు మరియు కథనాలు
- ✅ అఫిలియేట్ లింక్‌లు (Amazon Associates, Media.net, PropellerAds)
- ✅ SEO-friendly
- ✅ RSS Feed support
- ✅ Markdown & MDX support

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
